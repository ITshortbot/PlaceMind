# PlaceMind jury day checklist (Nov 20)

Demo path: guest mode. Google sign-in is NOT the demo path (it is tied to another app's port 8000 and redirect settings; leave them alone).

## URLs (code-server box)
- App: https://code.agromind.space/absproxy/3100
- Backend health: https://code.agromind.space/proxy/8100/health

## Before the jury (5 min)
1. Open the app URL. If it loads, continue. If not, run the restart command below.
2. Continue as guest. Add facts first (name, skills, a project, education) in the Resume Builder. Use only true information.
3. Send one chat message. Expect a real AI reply (free model, a few seconds).
4. Open /template, generate. Expect "Generated by model" and content built only from your facts.
5. Open /history. Past resumes and ATS scores should list. Open one in the editor.
6. Run an interview at /interview/new. It is deterministic and works offline.
7. ATS PDF upload: NOT browser-tested by the build agent. Test it by hand once with a real PDF before the jury. If it fails, skip it in the demo and show the saved ATS scores in /history.

## Demo script (about 5 min)
1. Landing page, one sentence on the idea.
2. Guest start, add facts in the builder.
3. Chat: ask for help improving a summary.
4. Template: generate, then use in builder.
5. History and ATS score.
6. Interview practice.
Say plainly: PlaceMind never invents jobs, numbers or dates. Thin input gives a thin resume on purpose.

## Power cut or crash: one command (in the code-server terminal)
    bash ~/project/placemind-up.sh
It starts Postgres, backend 8100 and frontend 3100 if down, then prints db, backend and frontend status. Expect "accepting connections", an online backend and 200. Safe to run twice. Do NOT stop anything on ports 8000 or 8002 (another project).
Logs: ~/project/pmlogs/backend.log and frontend.log.

## If the AI is slow or down
Chat and templates use a free OpenRouter model and can be slow or rate limited. Template falls back to a clearly labelled preset or an assembled-from-facts layout. Retry once, then continue with History and Interview.

## Fallback: GitHub Codespaces (run by you, untested by the agent)
1. github.com/ITshortbot/PlaceMind, branch feat/jury-prep (or main after merge): Code, Codespaces, Create codespace.
2. Terminal 1: cd backend && python -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt, then copy .env.example to .env, set DATABASE_URL to a Postgres you can reach and add your own OpenRouter free key (never commit it).
3. Start backend: uvicorn app.main:app --port 8100.
4. Terminal 2: cd frontend && npm ci && NEXT_PUBLIC_BACKEND_URL=<forwarded 8100 URL> npm run dev -- -p 3100 (Node 22). Make port 8100 public in the Ports tab.
5. Open the forwarded 3100 URL and run the same checklist. Without a key, chat is limited but the keyless flow (guest, builder, history, interview) still works.
This takes 15 to 25 minutes. Decide by 1 hour before the jury: if the server app does not load after the restart command, switch.

## Known limits
- Empty facts give an empty preview with an explanation (by design).
- Guest data is isolated per guest and expires.
- ATS upload untested in the browser.
